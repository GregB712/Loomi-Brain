# Code Of Conduct

## Standard

Contributors are expected to communicate respectfully, focus on technical substance, and avoid harassment, discrimination, or personal attacks.

## Scope

This applies to issues, pull requests, reviews, discussions, and any project-related communication.

## Enforcement

The repository owner may remove comments, close issues, block users, or reject contributions that violate this standard.

## Reporting

Report conduct concerns privately to the repository owner through GitHub.
