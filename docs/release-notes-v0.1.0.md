# Release Notes: v0.1.0 Candidate

This is a release-candidate note, not a deployed production claim.

## Included

- Owner-only local application stack.
- Hardened API/web security headers and request-size guard.
- In-memory login throttling for single-node deployments.
- Production-oriented Dockerfiles and Compose hardening.
- Local, cloud, and private/hybrid deployment documentation.
- Backup, restore verification, export, guarded local deletion, and DR smoke scripts.
- CodeQL, Trivy, SBOM, Dependabot, and manual release workflows.
- Portfolio README, runbooks, incident response, and demo walkthrough.

## Verification Required Before Tag

- Run the full local verification suite after the last change.
- Run GitHub CI and security workflows.
- Rehearse backup artifact verification.
- Capture screenshots from synthetic data.
- Confirm no secrets are committed.

## Not Claimed

- No cloud deployment has been performed.
- No production DNS, TLS certificate, account, or persistent managed service has been created.
- No real personal documents or credentials are included.
